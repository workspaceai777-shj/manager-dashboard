# Ontario Ayurvedic Medical Centre — Flutter Staff App

This Flutter Web project is developed on the **flutter-staff-app-v1** branch to preserve the original Vercel HTML dashboard on main.

## Features

- Firebase email/password authentication (Google Sheets stores user metadata and branch/category assignments, not passwords)
- Two branches: ONT-BB and ONT-BR1
- FRONT DESK category with distinct branch tasks
- INSURANCE USER category, available in either branch
- Multiple branch/category assignments for the same UID
- Individual Ledger Preparation recorded as EMR + remarks + minutes rows
- Other tasks entered as quantity + hours (collection as AED + hours)
- Manager summary of ledger preparations, updates, hours and collections
- Admin can assign authenticated Firebase users to multiple branch/categories

## Local build

Install Flutter 3.x and run `flutter pub get` from this folder.

Run the Flutter web app with `flutter run -d chrome` using Dart defines, for example:

```bash
flutter run -d chrome \
  --dart-define=API_BASE_URL=https://YOUR-VERCEL-PROJECT.vercel.app \
  --dart-define=FIREBASE_API_KEY=YOUR_PUBLIC_FIREBASE_API_KEY \
  --dart-define=FIREBASE_APP_ID=YOUR_PUBLIC_FIREBASE_APP_ID \
  --dart-define=FIREBASE_PROJECT_ID=YOUR_PROJECT_ID \
  --dart-define=FIREBASE_AUTH_DOMAIN=YOUR_PROJECT.firebaseapp.com \
  --dart-define=FIREBASE_MESSAGING_SENDER_ID=YOUR_SENDER_ID
```

Flutter Dart defines for Firebase's web project identifiers are not secrets. Never put Firebase Admin JSON or Google Sheet private keys in Flutter.

## Initialize Google Sheets app tabs

Use the separate `scripts/initialize_sheets.gs` Apps Script function on the existing workbook. It is non-destructive and creates only missing tabs.

In Firebase Authentication, enable **Email/Password**, create an initial admin user, copy that user's UID, and enter that exact UID, email, name, ADMIN, true in `App_Users`. Give this administrator assignments via `App_Assignments` or let the app's admin bootstrap grant category selection. The API checks authenticated Firebase UID against the Google Sheet.

Configure a Google Cloud service account with the Sheets API enabled and share the workbook with its service-account email as an Editor.

## Production deployment

The backend `api/v2.js` can run on Vercel. A Flutter Web build must first be generated by Flutter: `flutter build web --release [dart-defines]`, which produces `flutter_app/build/web`. For a standalone Flutter Vercel project, upload the compiled output to the static public directory or use CI to build and deploy. Do not switch the current HTML project to this branch until the Firebase and Google Sheets credentials, Flutter build and API authentication are verified.

## Limitations of this first implementation

- Admin registration supports adding users/assignments, but does not yet support revoking assignments or changing roles.
- There is no attendance validation or duplicate-report lock; each submission appends records.
- Dashboard currently shows ledger totals, hours, collection and employee counts; further graphical target and timeline widgets are needed before calling it complete.
- The target remains **ledger-only**; do not use other tasks as performance targets.
- The app has not yet been built/tested with Flutter SDK in this environment.
